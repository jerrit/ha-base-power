## Base Power 1.15.0

Live sensors work again. Base retired its older app API on November 24, 2026, and most live sensors read unknown from about 11:40 AM Central.

### Fixes
- **Live sensors went unknown** (#29, #30, #31). Battery Level, Battery Power, Power from Grid, Solar Power, Current Power, Backup Time, and Battery Connected stopped updating. After a restart, Grid Voltage and Grid Power did too, which broke outage automations. They now read from the calls that replace the old ones. The live poll also keeps running when Base sends no numeric location id, which it no longer does on some accounts (#30).
- **Battery Level on grid** is now worked out from Base's 750 W backup time. Base no longer sends the percent while the battery is on grid. Its source attribute reads `backup_hours_estimate`. It can trail the Base app by up to an hour, because Base updates that time every 15 minutes. During an outage, Base sends the exact percent and the sensor uses it (`source: snapshot`). The formula is from tchris227's comparison against the old percent over a full charge, which matched to within rounding (#29).
- **Backup Time (Current Load)** stayed unknown when it should have used the snapshot's value (#31).
- **Battery Charging stayed off during top-ups.** A full battery drifts to 99% every few hours, then charges back to 100% for 20 to 30 minutes. The sensor ignored that, because a rise from 99 to 100 looked like rounding. It now turns on whenever **Battery Power** shows power going into the battery (0.2 kW or more), even at 99 or 100%, and turns off as soon as that stops.
- **Battery Charging** read unknown on a battery sitting idle, sometimes for days. It now reads off. It still turns on when power goes in or the charge rises (#26).
- **Solar sensors** showed up on homes without solar that report 0.0001 kWh every hour. Solar now needs at least 0.05 kWh in a day (#26). Solar sensors already created stay; you can delete them.

### New
- **Base Core** is recognized from its battery model, `GEN3 SINGLE`, as 39.2 kWh (#26). Thanks to tchris227 for confirming it.
- When Base retires a call, Home Assistant logs one warning naming it, and the integration stops calling it until the next restart.
- About 125 calls an hour, down from 132.

### Correction to the 1.14.0 notes
1.14.0 listed "Battery Power has stayed at 0 while charging" as a known issue. That was wrong. On the retired call, Battery Power went negative while charging, about -0.2 to -1.0 kW during a top-up.

### Known issues
- The sign of Battery Power while charging hasn't been checked on the new data yet. Discharging is positive. If Battery Power reads positive while the battery charges, please open an issue.
- Grid Power during an outage hasn't been tested on the new calls. It turns off when Base flags an outage or the battery reports an off-grid state.
- Dual Base Core (`GEN3 DUAL`) is still estimated from the backup time. Diagnostics from a dual Core owner are welcome.

Restart Home Assistant after updating.
